### 🧩 **Work Request Schema**

Each structured task must be written in this exact order, using clear headings and bulleting for readability:

---

#### **Objective / Purpose**

Explain in one or two concise sentences **what specific outcome** the LLM must achieve.

#### **Scope / Boundaries**

Clarify what the LLM **should focus on** and **what is explicitly out of scope**.
If relevant, specify examples of what not to do.

#### **Inputs / Resources**

Concisely list all data, documents, links, or tools the LLM will need.
If any are missing or not yet provided, instruct the LLM to stop and request them before starting.

#### **Deliverables**

Concisely define exactly **what must be handed over**, including the format (e.g., Google Doc, table, bullet summary).
If multiple subtasks exist, list one deliverable per subtask.

#### **Success Criteria**

Concisely describe what **good output looks like**, including measurable or qualitative indicators of completeness, accuracy, and clarity.
For example: “Information is clearly sourced, formatted consistently, and free of unexplained terms.”
Explicitly instruct the LLM to rate its own performance, using whole integers out of 10, in adhering to each requirement in the task brief before task completion. 

#### **Critical Conduct Reminders**

**STRICT**: Always include the explicit behavioural instructions in [conduct-reminders.md](conduct-reminders.md) verbatim.
